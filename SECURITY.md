## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, please report them using **GitHub's Private Vulnerability Reporting** feature. This allows you to privately report vulnerabilities to the maintainers, ensuring that the issue is kept confidential until it is resolved.

To report a vulnerability:
1. Go to the **Security** tab of this repository.
2. Click on **Advisories** on the left sidebar.
3. Click on the **Report a vulnerability** button.
4. Provide details about the vulnerability, including how to reproduce it and its potential impact.

We will endeavor to respond to your report as soon as possible and keep you informed of our progress towards a fix. Thank you for helping keep our project safe!
