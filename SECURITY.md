# Security Policy

## Supported Versions

Currently, only the latest version of the `main` branch is supported with security updates. If you are using a specific release or tag, please update to the latest release to ensure you have the most up-to-date security patches.

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please do not report it through public issues or pull requests.

Instead, please use **GitHub's Private Vulnerability Reporting** feature to responsibly disclose the issue to the maintainers.

To do so:
1. Navigate to the **Security** tab of this repository.
2. Click on **Advisories** on the left sidebar.
3. Click the **Report a vulnerability** button.
4. Provide a detailed description of the vulnerability, including steps to reproduce it and any potential impact.

We will acknowledge receipt of your vulnerability report and strive to address it as quickly as possible. We will provide updates on our progress and notify you when a fix has been released.
