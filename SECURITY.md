# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of this project seriously.

If you discover a security vulnerability, we would appreciate it if you could report it privately so that we can fix it before it is disclosed publicly.

Please report vulnerabilities using **GitHub's Private Vulnerability Reporting** feature.
1. Go to the **Security** tab of this repository.
2. Click on **Advisories** in the sidebar.
3. Click on **Report a vulnerability**.
4. Fill out the form with details about the vulnerability.

We will review the submission as quickly as possible and get back to you. Please do not create public issues for security vulnerabilities.
