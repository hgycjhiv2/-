# Security Policy

## Supported Versions

Currently, the master/main branch is supported for security updates.

## Reporting a Vulnerability

We take the security of this project seriously.

To report a vulnerability, please use the GitHub Private Vulnerability Reporting feature for this repository:
1. Go to the "Security" tab of this repository.
2. Select "Advisories" in the left sidebar.
3. Click on the "Report a vulnerability" button.
4. Fill out the details of the vulnerability.

This will allow you to privately report the issue to the maintainers, who will assess and address it as quickly as possible. Please do not create public issues for security vulnerabilities.
