# Security Policy

## Supported Versions

Currently, only the latest version of the project is actively supported with security updates.

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us as described below.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please use GitHub's private vulnerability reporting to report any security vulnerabilities:
1. Navigate to the **Security** tab of this repository.
2. Click on **Advisories** in the sidebar.
3. Click on the **Report a vulnerability** button.
4. Provide details about the vulnerability, including how to reproduce it and its potential impact.

We will review your report, acknowledge receipt, and coordinate a fix and disclosure with you. We aim to address security vulnerabilities promptly.
