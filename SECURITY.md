# Security Policy

## Supported Versions

Please check the repository for the latest supported versions. We generally support the current major release.

## Reporting a Vulnerability

We take the security of this project seriously.

To report a security vulnerability, please use **GitHub's private vulnerability reporting** feature.

1. Go to the **Security** tab of this repository.
2. Click on **Advisories** on the left sidebar.
3. Click on the **Report a vulnerability** button.
4. Fill in the details of the vulnerability.

Please do not open a public issue for security vulnerabilities. Using GitHub's private vulnerability reporting ensures that the issue is disclosed responsibly to the maintainers without exposing it to the public before a fix can be prepared.

We will endeavor to respond to your report as quickly as possible.
