# Security Policy

## Supported Versions

We only provide security updates for the latest version of the project. If you are using an older version, please update to the latest release to ensure you have the latest security patches.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| Older   | :x:                |

## Reporting a Vulnerability

We take the security of our project seriously. If you discover a security vulnerability, please report it privately.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them using GitHub's Private Vulnerability Reporting feature:

1. Navigate to the **Security** tab of this repository.
2. Click on **Advisories** in the left sidebar.
3. Click the **Report a vulnerability** button.
4. Provide a descriptive title and a detailed description of the vulnerability, including steps to reproduce it.

We will acknowledge receipt of your vulnerability report and strive to provide a resolution or mitigation in a timely manner. Thank you for helping keep this project secure!
