# Security Policy

## Reporting a Vulnerability

We take the security of this project seriously. If you believe you have found a security vulnerability, please report it to us as described below.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them using GitHub's private vulnerability reporting mechanism. This allows us to receive and address the issue privately before making the vulnerability public.

1. Go to the [Security tab](../../security) of this repository.
2. Click on **Advisories** in the left sidebar.
3. Click on **Report a vulnerability**.
4. Fill in the details of the vulnerability, including a description, severity, and any proof of concept.
5. Submit the report.

We will review the report and work with you to resolve the issue as quickly as possible.
