# Security Policy

## Supported Versions

Currently, only the latest version of the project is supported with security updates.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.

Instead, please report them using **GitHub's private vulnerability reporting** feature. We take all security vulnerabilities seriously and will work to resolve them as quickly as possible.

To report a vulnerability:
1. Go to the **Security** tab in the repository.
2. Click on **Advisories** on the left side.
3. Click on **Report a vulnerability**.
4. Provide details about the vulnerability, including how to reproduce it and its potential impact.

We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress. If for some reason the private vulnerability reporting is unavailable, please check for alternative secure communication channels established by the repository maintainers.
