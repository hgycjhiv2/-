## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.

Instead, please report them using **GitHub's private vulnerability reporting**:

1. Navigate to the **Security** tab in this repository.
2. Click on **Advisories** in the left sidebar.
3. Click the **Report a vulnerability** button.
4. Fill in the details of the vulnerability, including a description, severity, and steps to reproduce.
5. Submit the report.

We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress. If you report a vulnerability, you may be eligible for public recognition once the issue has been resolved and a security advisory is published.

Thank you for helping to keep this project secure!
