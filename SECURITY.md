# Security Policy

## Supported Versions

Currently, only the latest version is supported with security updates.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, please report them using **GitHub's private vulnerability reporting feature**:
1. Go to the **Security** tab of the repository.
2. Click **Report a vulnerability** to open a private advisory.
3. Provide details about the vulnerability, the impact, and any potential fixes.

We take all security vulnerabilities seriously and will work to review and address your report as quickly as possible.
