# Security Policy

## Supported Versions

Please see our main project documentation or package registry for supported versions. We recommend staying on the latest release to ensure you have the most up-to-date security patches.

## Reporting a Vulnerability

We take the security of our project seriously.

If you discover a security vulnerability, please do **not** create a public issue. Instead, report it privately using GitHub's private vulnerability reporting feature.

### How to report:
1. Navigate to the **Security** tab of this repository.
2. Click on **Advisories** in the sidebar.
3. Click the **Report a vulnerability** button.
4. Provide a detailed description of the vulnerability, including:
   - The type of issue.
   - Steps to reproduce.
   - Potential impact.

Our team will review your report, acknowledge receipt, and begin working on a fix as soon as possible. Thank you for helping keep our project secure!
