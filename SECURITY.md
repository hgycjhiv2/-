# Security Policy

## Supported Versions

Currently, only the latest version of the project is supported with security updates.

## Reporting a Vulnerability

We take the security of our software seriously. If you believe you have found a security vulnerability, please report it to us as described below.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them using **GitHub's Private Vulnerability Reporting** feature. This allows us to receive and address security issues confidentially.

To report a vulnerability:

1. Go to the "Security" tab of this repository.
2. Click on "Advisories" in the left sidebar.
3. Click the "Report a vulnerability" button.
4. Fill out the form with as much detail as possible, including steps to reproduce the issue.

We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress.
