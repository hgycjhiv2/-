# Security Policy

## Supported Versions

Currently, only the latest version of this project is actively supported with security updates.

## Reporting a Vulnerability

We take the security of this project seriously.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them using **GitHub's private vulnerability reporting feature**. You can find this on the "Security" tab of this repository under "Advisories". This allows us to receive and address the issue confidentially before a patch is available.

We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress.
