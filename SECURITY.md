## Reporting a Vulnerability

We take the security of our project seriously. If you discover a security vulnerability, please do not report it through public GitHub issues.

Instead, please use GitHub's private vulnerability reporting mechanism to securely report the issue:
1. Navigate to the **Security** tab of this repository.
2. Click on **Advisories** in the left sidebar.
3. Click the **Report a vulnerability** button.

Provide as much detail as possible in your report, including:
* A description of the vulnerability.
* Steps to reproduce the issue.
* Potential impact.

Our team will review the report and work with you to address the issue securely before public disclosure.
