# Security Policy

## Supported Versions

We take the security of our project seriously. Currently, we provide security updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| v1.0.x  | :white_check_mark: |
| < v1.0  | :x:                |

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues.

Instead, please report them using **GitHub's Private Vulnerability Reporting**:
1. Go to the **Security** tab of this repository.
2. Click on **Advisories** in the left sidebar.
3. Click on **Report a vulnerability**.
4. Fill in the details of the vulnerability.

We will review your report and coordinate with you to resolve the issue responsibly.
