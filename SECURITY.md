# Security Policy

## Supported Versions

We currently support the following versions of the project with security updates:

| Version | Supported          |
| ------- | ------------------ |
| >= 1.0.x| :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

We take the security of our project seriously. If you discover a security vulnerability in this project, please report it to us privately.

**Do not open a public issue.**

Instead, please use GitHub's Private Vulnerability Reporting feature:
1. Navigate to the **Security** tab of this repository.
2. Click on **Advisories** in the sidebar.
3. Click the **Report a vulnerability** button.
4. Provide details about the vulnerability, including how to reproduce it and its potential impact.

We will review the report and work with you to resolve the issue as quickly as possible.
