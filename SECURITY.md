# Security Policy

## Supported Versions

Currently, the latest version of this repository is supported with security updates.

## Reporting a Vulnerability

We take the security of our systems very seriously. If you believe you have found a security vulnerability in this repository, please report it to us as described below.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them using **GitHub Private Vulnerability Reporting**. This allows you to privately report the vulnerability to the repository maintainers, so we can address it before it is made public.

To report a vulnerability:

1. Go to the **Security** tab of this repository.
2. Click on **Advisories** on the left sidebar.
3. Click on **Report a vulnerability** and provide details about the issue.

We will acknowledge your report as soon as possible and work with you to understand and fix the issue.

Thank you for helping keep this project secure!
