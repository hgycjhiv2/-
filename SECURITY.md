## Reporting a Vulnerability

We take the security of our systems and data very seriously. If you have found a security vulnerability in this project, we encourage you to report it to us.

Please report any security vulnerabilities using GitHub's private vulnerability reporting feature. Do not report security vulnerabilities through public GitHub issues.

To report a vulnerability:
1. Go to the **Security** tab of the repository.
2. Click on **Advisories** in the sidebar.
3. Click on **Report a vulnerability**.
4. Fill out the form with as much detail as possible.

We will review your report and respond as quickly as possible.
