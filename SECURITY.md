# Security Policy

## Supported Versions

Currently, only the latest version of the main branch is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| Main    | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us as described below.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them using GitHub's private vulnerability reporting feature:

1. Go to the [Security tab](https://github.com/repository/security) of this repository.
2. Click on "Advisories" in the left sidebar.
3. Click the "Report a vulnerability" button.
4. Provide details of the potential vulnerability, including steps to reproduce, potential impact, and any other relevant information.

A member of the repository team will acknowledge receipt of your vulnerability report, and we will strive to send you regular updates about our progress. If you report a vulnerability, we will work with you to assess the issue and develop a resolution.

Thank you for helping keep this project safe!
