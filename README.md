# المسابقة الوطنية للتعليق الصوتي

صفحة التسجيل في المسابقة الوطنية للتعليق الصوتي — جمعية الارتقاء الشبانية.

- موقع ثابت: `index.html` + الصور في `assets/`.
- التسجيل يتم مباشرة عبر واتساب (الرقم في `CONFIG.whatsapp` داخل `index.html`).
- لإضافة تاريخ آخر أجل: عدّل `CONFIG.deadline` (مثال: `'2026-11-15T23:59:00+01:00'`).
