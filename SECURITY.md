# Security Policy

## Supported Versions

Currently, this repository does not have specific version support rules, as it is an empty project. We recommend always using the latest changes if any source code is added.

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found a security vulnerability, please report it to us.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them using GitHub's Private Vulnerability Reporting mechanism:
1. Go to the "Security" tab of this repository.
2. Click on "Advisories" in the sidebar.
3. Click the "Report a vulnerability" button.

This ensures that the vulnerability details are kept confidential until a fix can be prepared and released.

We will endeavor to respond to your report promptly.
