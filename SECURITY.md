# Security Policy

## Supported Versions

We take the security of our project seriously. Currently, we provide security updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| >= 1.0  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, please report them using **GitHub's Private Vulnerability Reporting** feature. This allows you to privately report vulnerabilities to the repository maintainers, ensuring that the issue is not publicly disclosed before a patch is available.

To report a vulnerability:
1. Navigate to the **Security** tab of this repository.
2. Click on **Advisories** in the sidebar.
3. Click the **Report a vulnerability** button.
4. Provide a clear and detailed description of the vulnerability, including steps to reproduce, potential impact, and any suggested mitigations.

We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress.
