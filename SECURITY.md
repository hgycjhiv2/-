# Security Policy

## Supported Versions

Please see our release branches to see which versions are currently supported with security updates. We strongly encourage you to always use the latest version available.

| Version | Supported          |
| ------- | ------------------ |
| v1.0.x  | :white_check_mark: |
| < v1.0  | :x:                |

## Reporting a Vulnerability

We take the security of this project very seriously.

If you discover a vulnerability, **do not open a public issue.** Please report it by utilizing GitHub's Private Vulnerability Reporting feature.

To report a vulnerability:
1. Navigate to the **Security** tab of this repository.
2. Click on **Advisories** in the sidebar.
3. Click the **Report a vulnerability** button.
4. Fill in the details of the vulnerability, including how it can be reproduced and the potential impact.

Our team will review the submission, and you will be notified of the progress. We aim to triage all reports within 48 hours. Thank you for helping keep this project safe!
