# Security Policy

## Supported Versions

Currently, as this repository is in its initial setup phase and does not have formal releases, all code on the main branch is considered supported for security updates.

## Reporting a Vulnerability

We take the security of this project seriously.

If you discover a security vulnerability within this project, please do not disclose it publicly. Instead, please report it via GitHub's Private Vulnerability Reporting feature.

To report a vulnerability:
1. Go to the **Security** tab of this repository.
2. Click on **Advisories** in the left sidebar.
3. Click on **Report a vulnerability**.
4. Provide details about the vulnerability, including how to reproduce it and its potential impact.

We will review reports and work with you to resolve any confirmed issues promptly.
